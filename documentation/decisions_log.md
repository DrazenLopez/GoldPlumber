# Decisions Log

This document records archived architectural and project decisions. Use a new row for each decision and include links to relevant issues, PRs, or documents.

## How to use

- **Decision ID**: Short unique identifier (e.g. DEC-001).
- **Date**: Decision date (YYYY-MM-DD).
- **Decision**: Concise description of the decision made.
- **Status**: Proposed / Accepted / Rejected / Deprecated.
- **Owner**: Person or team responsible for the decision.
- **Rationale**: Short explanation of why the decision was made.
- **Consequences / Notes**: Implications, migration notes, follow-ups.
- **Links**: Related issues, PRs, or design docs.
